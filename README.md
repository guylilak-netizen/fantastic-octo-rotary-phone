# Simple BitLife-like Life Simulator (Python)

This is a minimal, text-based life simulator inspired by BitLife. Run the simulator with Python 3.8+.

Usage:

- Run interactively: python3 life_simulator.py
- Run full automatic life simulation: python3 life_simulator.py --auto
- Run for N years: python3 life_simulator.py --years 50

You can adjust randomness by setting the SEED environment variable or modifying the code.
